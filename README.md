# 枪战 PVP · 网页 3D 射击游戏 🎯

基于 **Three.js** 的浏览器 3D 第一人称射击游戏：**生化模式**生存闯关 + **1v1 联机单挑**，外加一个可视化的 **3D 地图编辑器**。

前端纯静态页面（Three.js 0.160 走 CDN），联机由零额外框架的 Node WebSocket 服务端（`ws`）驱动，**30Hz 状态广播 + 服务端权威判定**。

## 一、运行方式

### 方式 1：直接打开（生化模式单机）
双击 `index.html` 即可（推荐 Chrome / Edge）。Three.js 从 CDN 加载，需要联网。

### 方式 2：启动 Node 服务（含 1v1 联机）
```bash
npm install     # 首次，依赖仅 ws
npm start       # 或 node server.js，默认端口 8080
```
浏览器访问 `http://localhost:8080`（可用 `PORT=9000 npm start` 换端口）：

- 一台设备点「**1v1 单挑**」进入 `pvp.html`
- 另一台设备同样进入即可自动配对，**服务端满 2 人自动开局**
- 联机走 `ws://` WebSocket，同一局域网直接可用；公网需路由器做端口转发

### 可视化 3D 地图编辑器

打开 `map_editor.html`（需先 `node server.js`），可在 3D 视图里自由摆放：

高墙 · 矮墙 · 箱子 · 平台 · 坑道 · 窗户墙 · 柱子

## 六、项目结构

```
qiangzhan/
├── index.html          生化模式入口（主菜单 / 模式与地图选择 / 游戏主循环 / 全部武器与敌人逻辑）
├── pvp.html            1v1 联机单挑客户端（WebSocket 同步 + 弹道预测）
├── map_editor.html     可视化 3D 地图编辑器（OrbitControls 操控）
├── test_importmap.html Three.js importmap 连通性自检页
├── maps.json           地图数据（编辑器保存目标）
├── server.js           静态服务器 + 1v1 WebSocket 服务端（30Hz 广播、服务端权威判定）
└── package.json        启动脚本（npm start）
```

## 七、技术要点

- **渲染**：Three.js 0.160（ES Module + `importmap`），`PCFSoftShadowMap` 软阴影、半球光 + 平行光 + 点光源、雾效。
- **射击判定**：`Raycaster` 从准星中心发射，先与障碍物 `Box3` 求交，再与敌人命中盒求交，区分爆头 / 躯干。
- **命中反馈**：弹道曳光线、命中火花、暴击放大特效、屏幕准星变化。
- **角色控制**：胶囊体地面检测 + AABB 障碍物碰撞、重力与跳跃、俯仰角钳制。
- **后坐力与散布**：每把枪独立 `spread` / `moveSpread` / `jumpSpread`，移动与跳跃时精度下降。
- **联机架构**：服务端权威——客户端只上报输入，服务端计算命中与血量，30Hz 广播全场状态；客户端对远端玩家做位置插值，避免阶梯感。
- **性能**：活体敌人数量缓存（避免每帧 `filter`）、对象复用（子弹 / 火花 / 弹孔）。

## 常见问题

**Q：打开 `index.html` 后 3D 场景一片黑？**
多半是 Three.js CDN 没加载成功。打开 `test_importmap.html` 可以自检；国内网络建议配置代理，或把 `three.module.js` 下载到本地后改写 `importmap` 路径。

**Q：联机连不上？**
确认 `node server.js` 已启动、两端访问的是同一地址；公网联机需要在路由器上把 8080 端口转发到本机内网 IP。

**Q：想自己改地图？**
启动服务端后打开 `map_editor.html`，编辑完点「保存地图」，会直接写回 `maps.json`。
